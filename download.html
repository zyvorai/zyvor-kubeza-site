How you will verify a release

This is the plan. Each release is intended to carry a checksum file, a signature and an SBOM. The file names below are placeholders.

1. Checksums

sha256sum -c SHA256SUMS --ignore-missing

2. Signature

# signing tool and key to be published with the first release
<verify-tool> verify SHA256SUMS SHA256SUMS.sig

3. SBOM

# an SBOM file will be published next to each artefact
less zkube.sbom.json
