Quickstart

Four commands from a bare Linux host to a checked cluster. This describes the planned command line; no binary is released yet, so the output shown is illustrative.

Preview. Command names and output may change before the first build. Want to try it first? Request early access.

1. Check the host

Preflight inspects the machine and reports what to fix. It changes nothing.

zkube preflight

2. Review the plan

Choose a solution profile and see exactly what an install would do.

zkube plan --profile edge-retail

3. Install the server

Installs from a verified bundle. For sites without internet, use an offline signed bundle.

sudo zkube install server

4. Run the doctor

Confirms that the cluster, gateway and hardening are in the state the plan described.

zkube doctor
