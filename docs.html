Docs

An overview of the ideas and commands. Full documentation will arrive with the first build; commands here are planned and may change.

Concepts

Built on K3s

Zyvor Kubeza is built on K3s and is not K3s. K3s is a trademark of SUSE; Zyvor Kubeza is not affiliated with SUSE or Rancher.

Setura Gateway

The Setura Gateway API controller is built in instead of Traefik. Routing is configured with Gateway API resources.

Netra (optional)

eBPF network observability you can enable per cluster.

Profiles

Edge Retail, Private Cloud with VMs, GPU AI, Factory Edge and Hospital Edge: starting points for add-ons and hardening.

Bundles

Signed archives for offline install and upgrade, verified before use.

Licence

A signed offline licence, verified locally. It never stops a running cluster.

Commands

CommandPurpose
zkube preflightCheck the host before install.
zkube planShow what an install would do. Changes nothing.
zkube install serverInstall a server node.
zkube doctorCheck cluster health and configuration.
zkube upgradeUpgrade, with automatic rollback on failure.
zkube backup / restoreBack up and perform a verified restore.
zkube hardenApply hardening and export an auditor evidence bundle.
zkube addonEnable and manage add-ons.

Exact subcommands and flags for everything beyond preflight, plan, install and doctor are not final.
